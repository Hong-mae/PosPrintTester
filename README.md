# POSTester — POS 프린터 · 금전함 점검 도구

영수증 프린터와 금전함이 제대로 붙었는지 현장에서 바로 확인하는 프로그램입니다.
**USB 에 `POSTester.exe` 하나만 담아 다니면 됩니다.** 설치도, 관리자 권한도 필요 없습니다.

대상 장비: POSBANK APEXA X-1500 (1024 x 768 터치) · 범일금고 EC-410 금전함

---

## 1. 5분 안에 끝내기

1. USB 를 꽂고 **`POSTester.exe` 를 두 번 클릭**합니다. (설치 과정 없음)
2. 화면 왼쪽 **방식** 에서 프린터가 연결된 방법을 고릅니다.
   - 프린터에 **9핀 케이블**(D-sub) 이 꽂혀 있으면 → **시리얼 (COM 포트)**
   - 프린터에 **네모난 USB 케이블**이 꽂혀 있으면 → **USB (윈도우 프린터)**
3. **포트** 를 고릅니다. 어느 것인지 모르면 목록에 나오는 것을 위에서부터 시도합니다.
4. 시리얼이라면 **[통신 속도 자동 찾기]** 를 누릅니다. 맞는 속도를 알아서 찾아 줍니다.
5. **[연결]** 을 누릅니다. 화면 맨 위가 초록색 **연결됨** 으로 바뀌면 성공입니다.
6. **[연결 테스트]** → **[출력 테스트]** → **[2번 핀 열기]** 순서로 눌러 확인합니다.

전부 한 번에 하려면 맨 아래 **[전체 테스트 순차 실행]** 하나만 누르면 됩니다.
(금전함이 두 번 열리고 용지가 잘립니다.)

## 2. 화면 보는 법

```
┌──────────────────────────────────────────────────────────┐
│ ● 연결됨   COM3 · 38400 · 8N1              [ 전체화면 ]  │ ← 지금 연결 상태
├──────────────────────────────────────────────────────────┤
│ 프린터 온라인 │ 커버 닫힘 │ 용지 충분 │ 절단기 정상 │ 금전함 닫힘 │ ← 프린터가 알려주는 상태
├──────────────────┬───────────────────────────────────────┤
│ 연결             │ 프린터 테스트 · 금전함 · 용지 · 절단  │
│ (방식/포트/속도) │ (누를 버튼들)                          │
├──────────────────┴───────────────────────────────────────┤
│ 로그 — 방금 무슨 일이 있었는지 시간 순서대로 기록         │
└──────────────────────────────────────────────────────────┘
```

- **맨 위 줄**이 제일 중요합니다. **연결됨**(초록) 이 아니면 아무 버튼도 듣지 않습니다.
- **상태 띠**의 글자 색이 의미입니다. 초록 = 정상, 주황 = 확인 필요, 빨강 = 문제.
- 버튼을 누르면 그 버튼 테두리가 잠깐 **초록(성공)** 또는 **빨강(실패)** 으로 바뀝니다.
- **F11** 을 누르면 전체화면으로 바뀝니다. 다시 누르면 돌아옵니다.

### 버튼 설명

| 버튼 | 하는 일 |
|---|---|
| 연결 테스트 | 프린터를 초기화하고 상태 4가지를 읽어옵니다 |
| 출력 테스트 | 한글·영문·숫자·금액·정렬·굵게·밑줄을 한 장에 인쇄합니다 |
| 상태 새로고침 | 상태 띠를 다시 읽습니다 |
| 초기화 | 프린터를 처음 상태로 되돌립니다 |
| 2번 핀 / 5번 핀 열기 | 금전함을 엽니다. **기종마다 배선이 달라 둘 다 눌러 봐야 합니다** |
| 리얼타임 열기 | 인쇄 대기열을 무시하고 즉시 엽니다 (프린터가 멈춰 있을 때) |
| 전체 절단 | 용지를 완전히 자릅니다 |
| 부분 절단 | 한 점만 남기고 자릅니다 (손으로 뜯게) |
| 피드 후 절단 | 설정한 줄 수만큼 밀어낸 뒤 자릅니다 — **평소엔 이걸 쓰세요** |
| 피드만 | 자르지 않고 용지만 밀어냅니다 |
| 직접 명령 | ESC/POS 명령을 16진수로 직접 보냅니다 (문제 파악용) |

> **절단 전 피드**를 0으로 두면 인쇄한 마지막 줄이 잘려 나갑니다. 기본값 **3줄**을 권합니다.

## 3. 문제가 생겼을 때

### 금전함이 안 열립니다

화면의 **[안 열려요?]** 를 누르면 같은 내용이 나옵니다. 이 순서대로 확인하세요.

1. **반대쪽 핀으로 다시 시도** — 2번 핀이 안 되면 5번 핀. 기종마다 배선이 다릅니다.
2. **솔레노이드 전압 확인** — EC-410 은 **12V 모델과 24V 모델이 따로** 있습니다.
   24V 금전함을 12V 포트에 물리면 **"딸깍" 소리만 나고 열리지 않습니다.** 가장 흔한 원인입니다.
3. **RJ-11 / RJ-12 케이블** 이 프린터의 **DK(금전함) 포트**에 끝까지 꽂혔는지 확인.
   전화선 포트처럼 생겨서 헐겁게 걸쳐진 경우가 많습니다.
4. **금전함 측면 수동 키** 가 잠금(LOCK) 위치인지 확인. 잠겨 있으면 신호가 가도 안 열립니다.

### 연결이 안 됩니다 (시리얼)

| 증상 | 확인할 것 |
|---|---|
| 응답이 전혀 없음 | **[통신 속도 자동 찾기]** 를 먼저 눌러 보세요 |
| 자동 찾기도 실패 | 케이블이 **크로스(널모뎀)** 여야 하는 기종일 수 있습니다 |
| 자동 찾기도 실패 | 프린터 설정의 **흐름 제어**(RTS-CTS / DTR-DSR)를 화면 설정과 맞추세요 |
| "포트를 열 수 없습니다" | POS 프로그램이 그 포트를 이미 쓰고 있습니다. POS 를 먼저 끄세요 |
| 포트 목록이 비어 있음 | USB-시리얼 변환기 드라이버가 설치되지 않았습니다 |

### 상태 조회 버튼이 회색입니다

**USB(윈도우 프린터)** 연결은 프린터로 **보내기만** 할 수 있어서 상태를 읽을 수 없습니다.
상태 확인이 필요하면 **시리얼(COM 포트)** 로 연결하세요. 인쇄와 금전함은 USB 로도 잘 됩니다.

### 한글이 깨져서 나옵니다

프린터 자체의 코드페이지 설정이 **KS5601 / cp949 / 한국어** 로 되어 있어야 합니다.
프린터 설정 인쇄물이나 DIP 스위치를 확인하세요.

### 로그를 남기고 싶습니다

오른쪽 아래 **[파일로 저장]** 을 누르면 화면의 로그가 텍스트 파일로 저장됩니다.
본사에 문의할 때 이 파일을 함께 보내면 원인 파악이 빨라집니다.

## 4. 설정 저장

마지막으로 쓴 연결 방식·포트·속도·흐름 제어·절단 줄 수가 자동으로 저장되고
다음 실행 때 그대로 복원됩니다.

```
%APPDATA%\POSTester\config.json
```

설정을 초기화하려면 이 파일을 지우고 다시 실행하면 됩니다.
파일이 깨져 있어도 프로그램은 기본값으로 정상 실행됩니다.

## 5. 하드웨어 없이 연습하기

방식에서 **가상 프린터 (연습용)** 을 고르면 실제 장비 없이 모든 버튼을 눌러 볼 수 있습니다.
가짜 프린터가 상태를 만들어 응답하고 금전함도 열린 것처럼 동작합니다.
교육이나 데모에 쓰세요.

## 6. 개발자용

### 구조

```
pos_tester/
├── core/            # Qt·화면에 의존하지 않는 순수 로직 (pytest 로 단독 검증)
│   ├── escpos.py    #   ESC/POS 명령 생성 + 상태 비트 해석
│   ├── encoding.py  #   cp949 인코딩 (변환 불가 문자는 예외 대신 '?' 로 대체)
│   ├── transport.py #   Transport 추상 + Serial / WinSpooler / Mock
│   ├── discovery.py #   포트·프린터 열거, 통신 속도 자동 탐색
│   ├── tester.py    #   테스트 시나리오 (transport 만 주입받음)
│   └── errors.py    #   사용자에게 그대로 보여줄 수 있는 예외 계층
├── ui/
│   ├── main_window.py
│   ├── worker.py    #   QThread 워커 — 모든 I/O 는 여기서만 일어난다
│   ├── widgets/
│   ├── theme.qss    #   {{토큰}} 자리표시자만 있고 값은 tokens.py 에 있다
│   └── tokens.py    #   색상·간격·타이포·터치 크기의 단일 출처
├── config.py        # %APPDATA% 에 JSON 저장/복원
└── main.py
```

원칙 세 가지:

- **`core/` 는 `PySide6` 를 임포트하지 않는다.** 하드웨어도 화면도 없이 테스트할 수 있어야 한다.
- **UI 스레드에서 I/O 를 하지 않는다.** 모든 작업은 `worker.submit(Job)` 으로 넘기고 시그널로 결과를 받는다.
- **예외를 삼키지 않는다.** `PosTesterError` 로 감싸 사람이 읽을 수 있는 메시지 + 조치 힌트로 바꾼다.

### 디자인 토큰

색상·간격·글자 크기는 전부 `pos_tester/ui/tokens.py` 에 있습니다.
`theme.qss` 는 `{{accent}}` 같은 자리표시자만 쓰고 실행 시 치환되므로,
**색을 바꾸려면 QSS 가 아니라 `tokens.py` 를 고치세요.**

- 배경: `#16181C` / 카드 `#1D2025` / 보더 `#2E333A` (채도 낮은 뉴트럴)
- 액센트: 뮤트 틸 `#4C9A8F` 하나만 사용
- 상태: 정상 `#74A97C` · 경고 `#C39A55` · 오류 `#C4706A` (원색 없음)
- 간격: 4px 배수 스케일 — 4 / 8 / 12 / 16 / 20 / 24 / 32
- 타이포 3단계: 제목 18px / 본문 14px (버튼 15px) / 캡션 12px
- 터치: 주요 버튼 56px, 보조 44px, 콤보 46px·드롭다운 항목 44px, 버튼 간격 8px

> Qt 스타일시트의 `min-height` 는 **내용 영역** 기준이라 padding·border 가 그 위에 더해집니다.
> `tokens.py` 의 `_content_height()` 가 이걸 역산해 주므로, 실제 터치 타깃 높이는
> `TOUCH` 에 적힌 값 그대로 그려집니다. 이 계산을 건드리면 `tools/ui_check.py` 로 다시 확인하세요.

### 개발 환경

```bash
python -m pip install -r requirements-dev.txt

python -m pytest tests/ -v          # core 단위 테스트
python main.py                      # 실행

# UI 전체 플로우 검증 (Mock 으로 연결부터 전체 테스트까지 실제로 클릭)
python tools/ui_check.py            # Windows
xvfb-run -a python tools/ui_check.py  # Linux (화면 없이)
```

`tools/ui_check.py` 는 1024x768 에서 잘리는 곳이 없는지, 터치 타깃이 56px 이상인지,
버튼 색이 의도한 값으로 렌더되는지까지 확인하고 단계별 스크린샷을 남깁니다.

### 빌드

**Windows PC 에서** `build\build.bat` 을 실행하면 끝입니다.
가상환경 생성 → 패키지 설치 → 아이콘 생성 → `dist\POSTester.exe` 까지 한 번에 합니다.

수동으로 하려면:

```bat
python -m pip install -r requirements-build.txt
python build\make_icon.py
python -m PyInstaller --clean --noconfirm build\POSTester.spec
```

`build/POSTester.spec` 에서 챙긴 것:

- `--onefile --windowed` — 파일 하나, 콘솔 창 안 뜸
- `uac_admin=False` — 관리자 권한 요구 안 함 (UAC 프롬프트 없음)
- hidden import — `serial.tools.list_ports`, `win32print`, `win32timezone`
  (특히 `win32timezone` 이 빠지면 실행 직후 ImportError 로 창이 안 뜹니다)
- `datas` — `theme.qss` 와 `icon.ico` 는 코드가 아니라서 따로 넣어 줘야 합니다
- `excludes` — QtQuick / QtWebEngine / QtMultimedia 등 안 쓰는 Qt 모듈 제외
- `upx=False` — UPX 압축은 백신 오탐을 자주 부르므로 끕니다
- **`shiboken6` 은 excludes 에 넣지 말 것** — PySide6 가 임포트되는 순간 부르는 모듈이라
  빼면 exe 가 실행 직후 `ModuleNotFoundError` 로 죽습니다 (창이 아예 안 뜹니다)
- 한글 폰트는 넣지 않습니다. Windows 기본 탑재인 **맑은 고딕(Malgun Gothic)** 을 씁니다

실제 POS 단말기(Intel N95, DDR4 4GB)는 측정 환경보다 느리므로
**첫 실행은 더 걸릴 수 있습니다.** USB 에서 바로 실행하면 USB 읽기 속도까지 더해집니다.

> `--onefile` 은 실행할 때마다 임시 폴더로 압축을 풀기 때문에 첫 실행이 특히 느립니다.
> 매번 빠르게 띄워야 한다면 `.spec` 의 `EXE(...)` 를 `COLLECT(...)` 로 바꿔
> 폴더 형태(`--onedir`)로 빌드하세요. 파일이 여러 개가 되는 대신 실행이 빨라집니다.

## 7. 참고 — 쓰는 ESC/POS 명령

| 기능 | 바이트 | 비고 |
|---|---|---|
| 초기화 | `1B 40` | ESC @ |
| 프린터 상태 | `10 04 01` | 온·오프라인, 커버, 금전함 핀3 |
| 오프라인 원인 | `10 04 02` | 커버 열림, 용지 없음 |
| 에러 상태 | `10 04 03` | 절단기 에러, 복구 가능·불가 |
| 용지 센서 | `10 04 04` | 용지 없음 / 거의 없음 |
| 다국어 모드 진입 | `1C 26` | FS & — 한글 출력 전 필수 |
| 다국어 모드 해제 | `1C 2E` | FS . |
| 금전함 2번 핀 | `1B 70 00 19 FA` | on 50ms / off 500ms |
| 금전함 5번 핀 | `1B 70 01 19 FA` | |
| 금전함 리얼타임 | `10 14 01 00 02` | 출력 버퍼 무시 |
| 전체 절단 | `1D 56 00` | GS V 0 |
| 부분 절단 | `1D 56 01` | GS V 1 |
| 피드 후 절단 | `1D 56 42 n` | GS V B n — n 줄 밀어낸 뒤 절단 |
| 피드 | `1B 64 n` | ESC d n |

`10 04 01` 응답 비트 해석:

| 비트 | 값 | 뜻 |
|---|---|---|
| bit2 (`0x04`) | 0 | 금전함 **열림** (핀3 LOW) |
| bit2 (`0x04`) | 1 | 금전함 닫힘 또는 미연결 |
| bit3 (`0x08`) | 1 | 오프라인 |
| bit5 (`0x20`) | 1 | 커버 열림 |
| bit6 (`0x40`) | 1 | 용지 피드 버튼 눌림 |

bit0 · bit7 은 항상 0, bit1 · bit4 는 항상 1 입니다.
이 규칙을 만족하지 않는 바이트는 **통신 속도가 안 맞아 깨진 응답**으로 보고 무시합니다.
속도 자동 탐색이 이 성질을 이용합니다.
